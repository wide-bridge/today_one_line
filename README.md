# 오늘의 한 줄

서버·계정·외부 라이브러리 없이 동작하는 모바일 우선 개인 기록 웹앱입니다. 구현 기준은 D01 SPEC v1.0입니다.

## 실행

`npm start` 또는 `python -m http.server 8000 --directory dist` 실행 후 http://localhost:8000 에 접속합니다. `file://` 직접 열기는 지원하지 않습니다. Node.js는 테스트에만 필요합니다.

## 구현 범위

- 로컬 날짜별 고정 문장과 스냅샷, 자정 전환
- IndexedDB 메모 자동 저장(500ms), 그림 정규화 좌표 저장, 실행 취소
- 과거 기록 수정, 월 필터, 문장/메모 검색, 문장 즐겨찾기
- 네 가지 테마, JSON 백업 및 검증/미리보기/트랜잭션 복원
- 문장·메모·그림 PNG 생성, 지원 기기의 파일 공유
- 정적 자산 오프라인 캐시, 새 버전 안내

`dist/`가 배포 가능한 정적 웹 루트입니다. 영화 대사 후보는 `data/quotes.film-review.json`에 비활성 상태로 보관하며 배포 폴더에 포함하지 않습니다. 이 후보의 출처 재검증이나 배포 승인은 수행하지 않았습니다.

## 데이터

IndexedDB `one-line-db` v1: `entries`, `assignments`, `favorites`, `settings`. 문장 배정만 있는 날은 기록 목록에 나타나지 않습니다. 병합은 같은 날짜의 백업 기록을 우선하며 덮어쓰기는 기존 데이터 전체를 교체합니다. 가져오기는 20MB, 메모 2,000자, 300획, 획당 1,500점, 기록당 30,000점으로 제한됩니다. localStorage에는 테마만 저장합니다.

브라우저 저장소는 기기 및 사이트 주소별로 분리되며 자동 동기화되지 않습니다. 브라우저의 강제 종료 직전 완료되지 않은 쓰기는 보장할 수 없으므로 저장 상태와 백업을 확인하세요.

## 검증

`npm test`: 날짜 선택, 카탈로그 필터, 백업 검증/경계/주입 데이터 처리 및 정적 자산 참조 검사. 실제 iPhone Safari, Android Chrome, 데스크톱 Safari/Chrome의 터치·회전·오프라인·공유·저장 공간 부족 시나리오는 별도 기기 검증이 필요합니다.

서비스 워커 자산을 변경해 배포할 때는 `CACHE` 버전을 함께 올리세요. HTTPS 또는 localhost에서 서비스 워커가 동작합니다.
